# Ember
A very brief look into how languages compile. 

This project let me explore: reading strings in the lexer, tree construction in the parser and tree traversal in the interpreter. It was a good opportunity to practice my fundamentals of programming.

I would like to return to this project in the future and dive deeper into memory management paradigms, compilation into binary and interesting features such as parallelism and distributed systems. I would also like to add a cli to use the language more effectively.
